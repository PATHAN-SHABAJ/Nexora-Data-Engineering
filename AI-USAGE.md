# AI Usage

I used AI during the development of this project mainly as a coding and debugging assistant.

I used it for:

- Understanding the challenge requirements and data pipeline structure.
- Getting help with Python and Pandas implementation.
- Debugging errors during development.
- Improving the organization of the pipeline into separate modules.
- Reviewing Git and project structure before submission.

I did not use AI to replace the complete implementation without checking the results. I ran the code locally and checked the generated outputs.

One issue I caught during development was that some generated files and development scripts were not suitable for the final repository. I checked the Git status and staged only the files required for the submission.

The final predictions were also checked using the provided validation script.
